# mybrain-backup

作者自身のノート (Obsidian の vault) を Google Drive へバックアップするための個人用ツールです

手元の Mac にあるノートを毎晩1つのアーカイブにまとめ、Google Drive のバックアップ用フォルダへ保存します  世代管理により一定数のみを残し、古いアーカイブは自動で削除します

一般への配布は行っておらず、利用者は作者本人のみです  このリポジトリには、Google の OAuth 同意画面に必要なホームページとプライバシーポリシーの2ページのみを配置しています  バックアップの本体 (シェルスクリプトと LaunchAgent) は手元の Mac にあり、このリポジトリには含みません
